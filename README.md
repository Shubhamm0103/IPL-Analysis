# IPL-Analysis

## Project Overview

This project presents an interactive **IPL Data Analysis Dashboard** developed using **Tableau**. The dashboard analyzes Indian Premier League (IPL) data to provide insights into player performance, team statistics, match outcomes, scoring patterns, and venue-based trends.

The project focuses on transforming raw cricket data into clear and interactive visualizations, enabling users to explore and compare IPL statistics efficiently.

## Objectives

* Analyze IPL match and player performance data
* Identify top-performing batsmen and bowlers
* Compare batsman performance against different bowlers
* Analyze batsman performance against different teams
* Explore scoring patterns across IPL matches
* Analyze matches based on venues and locations
* Present cricket statistics through interactive Tableau visualizations

## Dashboard Features

### IPL Overview

The IPL Overview dashboard provides a high-level summary of IPL data, including:

* Match and season analysis
* Team performance insights
* Venue-based analysis
* Geographic distribution of IPL matches
* Key tournament statistics

### Batsman Analysis

The Batsman Analysis dashboard provides detailed insights into batting performance, including:

* Best Batsman Analysis
* Batsman vs Bowler Analysis
* Batsman vs Team Analysis
* Batting Average Analysis
* Scoring Shot Analysis

### Bowling Analysis

Bowling performance is analyzed using wicket and dismissal information. The analysis helps identify successful bowlers and compare bowling performances across players.

### Venue Analysis

IPL matches are analyzed based on cities and venues to understand the geographical distribution of matches and identify frequently used IPL venues.

## Dataset

The project uses IPL match-level and ball-by-ball delivery data.

### Match Data

Key attributes include:

* Season
* Date
* City
* Venue
* Team 1
* Team 2
* Toss Winner
* Toss Decision
* Match Winner
* Player of the Match
* Winning Margin

### Ball-by-Ball Data

Key attributes include:

* Match ID
* Innings
* Over
* Ball
* Batting Team
* Bowling Team
* Batsman
* Bowler
* Batsman Runs
* Extra Runs
* Total Runs
* Player Dismissed
* Dismissal Type
* Fielder

## Key Analysis

The dashboard explores questions such as:

* Who are the top-performing batsmen in the IPL?
* Who are the most successful bowlers?
* How does a batsman perform against a specific bowler?
* How does a batsman perform against different IPL teams?
* What are the major scoring patterns?
* Which venues have hosted the most IPL matches?
* How are IPL matches geographically distributed?

## Tools and Technologies

* **Tableau** – Data visualization and interactive dashboard development
* **IPL Match Dataset** – Match-level analysis

## How to Use

1. Clone or download this repository.
2. Download the `IPL Analysis.twbx` file.
3. Open the workbook using **Tableau Desktop** or a compatible version of Tableau.
4. Navigate through the available dashboards.
5. Use the interactive filters to explore player, team, bowler, and venue-level statistics.
